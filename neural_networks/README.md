# Neural Network Lab Exercises

This directory contains deep learning implementations and exploratory data analysis tasks developed using `PyTorch` (or `TensorFlow`) and Python.

## Topics Covered

* **01_least_squares**: Implementation of least squares regression as a foundation for gradient-based optimization, analyzing loss surfaces and closed-form vs. iterative solutions.
* **02_undercomplete_autoencoders**: Implementation of undercomplete autoencoders for dimensionality reduction, focusing on bottleneck representations and reconstruction loss.
* **03_VAE_autoencoders**: Variational Autoencoders (VAE), exploring the reparameterization trick, latent space regularization, and generative sampling.
* **04_GAN**: Implementation of Generative Adversarial Networks, analyzing the generator-discriminator training dynamics and adversarial loss.
* **05_WGAN**: Wasserstein GAN implementation, focusing on the Earth Mover's distance, weight clipping/gradient penalty, and training stability improvements over vanilla GANs.
* **06_transformer_seq_generation**: Transformer-based sequence generation, covering self-attention mechanisms, positional encoding, and autoregressive decoding.
* **07_GNN_graph_prediction**: Graph Neural Networks for graph-level prediction tasks, exploring message passing and graph pooling strategies.
* **08_GNN_node_prediction**: Graph Neural Networks for node-level prediction (node classification), analyzing neighborhood aggregation techniques.
* **09_GNN_link_prediction**: Graph Neural Networks for link prediction, focusing on edge embedding and similarity-based scoring functions.
