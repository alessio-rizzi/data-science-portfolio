# Deep Learning & Machine Learning Lab Exercises

This repository collects lab exercises and implementations covering both classical machine learning and deep learning, developed in Python.

## Folder Structure

* **machine_learning**: Classical machine learning implementations and exploratory data analysis tasks built with `scikit-learn`. Covers decision trees, feed-forward neural networks (MLP), Bayesian classifiers, clustering (DBSCAN), and K-Nearest Neighbors.
* **neural_networks**: Deep learning implementations built with `PyTorch`. Covers least squares as an optimization foundation, autoencoders (undercomplete and variational), generative adversarial networks (GAN and WGAN), transformer-based sequence generation, and Graph Neural Networks (graph, node, and link prediction).

## Tech Stack & Libraries

* **Language**: Python
* **Core Libraries**: Scikit-Learn, PyTorch, NumPy, Matplotlib, SciPy
